Testimonial Card UI Component

A modern, reusable testimonial card component for SaaS, startup, and portfolio websites, with theme and language toggles.

Frontend · UI Component
Frontend Developer

About this Project

This project showcases a clean, technology-inspired testimonial card built with a strong focus on UI structure, visual hierarchy, spacing, alignment, and typography.

The component is minimal and reusable, suitable for SaaS or startup landing pages, personal portfolio projects, and UI component libraries. It ships with both dark and light presentations out of the box.

Key Features

Centred testimonial card layout
Dark and light theme support
Language toggle between English and Khmer
Glassmorphism-inspired design
Smooth micro-interactions and animations
Circular avatar with accent styling

Key Achievements

1

Designed a reusable component that works standalone in landing pages and portfolios.

2

Implemented theme and language switching with vanilla JavaScript state handling.

3

Focused on accessible, readable typography and consistent spacing throughout.
