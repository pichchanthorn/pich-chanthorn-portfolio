Khmer Music+ Pricing Cards

A responsive subscription pricing interface for an online music streaming service, with three structured plans and clear visual hierarchy.

Frontend · Coursework
Web Design Coursework

About this Project

This project builds the subscription pricing page for an online music service called Khmer Music+. It displays three plans — Basic, Standard, and Premium — with the Standard plan highlighted as the main offer.

It was produced as Web Design coursework (Homework Week 06 & 07) with the goal of practising semantic HTML structure and CSS styling, using the Kantumruy Pro Google Font for Khmer-friendly typography.

Key Features

Three-tier subscription plan layout
Highlighted recommended plan
Responsive card grid
Clear pricing visual hierarchy
Kantumruy Pro typography for Khmer text
Separate A4-style assignment description page

Key Achievements

1

Practised structuring a full pricing page with semantic HTML and pure CSS.

2

Established a clear visual hierarchy that guides users toward the recommended plan.

3

Applied Khmer-friendly web typography through a Google Font.

Tech Stack
