Khmer Tech Job Application Website

A responsive multi-page job application website with structured forms, client-side validation, and a clean technology-themed layout.

Frontend · Coursework
Web Programming Coursework

About this Project

This project simulates a company called Khmer Tech Solutions, where users can browse job vacancies and submit an application online. It was created as a course assignment to practise building a multi-page website with core web technologies.

The home page carries the application form — personal information, position selection, job type, skills, CV upload, and reason for applying — while a separate jobs page lists the available vacancies and links back to the form.

Key Features

Multi-page structure with home and jobs pages
Personal information application form
Job position and job type selection
Skills selection with checkboxes
PDF CV upload field
JavaScript validation with success feedback
