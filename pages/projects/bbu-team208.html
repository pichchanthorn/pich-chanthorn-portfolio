BBU Gen25 – Team 208 Website

An academic group website for Build Bright University Generation 25, Team 208, built for the Web Programming course.

Frontend · Group Project
Frontend Developer / Team Lead

About this Project

This is the academic group website developed by Build Bright University (BBU), Generation 25, Team 208 for the Web Programming course. It demonstrates collaborative front-end development through a structured, multi-page static website.

The site combines semantic HTML, a modular CSS architecture, and JavaScript interactivity across six pages, and is deployed to GitHub Pages under a custom domain. The scope is front-end only — no backend, database, or admin panel.

Key Features

Six-page team and project showcase
Responsive across desktop, tablet, and mobile
Reusable design system with modular CSS
Theme-aware styling and interaction patterns
Team profile section with role-focused presentation
Contact form with validation and Formspree delivery
Optimised WebP imagery and Open Graph tags

Key Achievements

1

Led front-end development for a six-page team website deployed on a custom domain.

2

Built a reusable design system and modular CSS shared across every page.

3

Wired a validated contact form to real email delivery through Formspree.
