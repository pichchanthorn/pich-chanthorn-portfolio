PCTN Fertilizer Business Website

A professional multi-page business showcase presenting fertilizer products and company information, built with vanilla HTML, CSS, and JavaScript.

Frontend
Frontend Developer

About this Project

This website presents the fertilizer products and company information for PCTN Fertilizer Shop. Customers can explore the product range and contact the business directly by phone or Telegram.

It is a four-page static site — home, products, about, and contact — built with vanilla HTML, CSS, and JavaScript and organised with a clean assets structure, so it deploys to GitHub Pages, Netlify, or Vercel with no build step.

Key Features

Four-page business site structure
Responsive design across screen sizes
Modern, professional UI
Smooth animations and transitions
Contact-based ordering system
Clean, dependency-free code structure

Key Achievements

1

Delivered a complete business website with no framework or build dependencies.

2

Implemented a contact-based ordering path through phone and Telegram.

3

Organised styles and scripts into a maintainable assets structure ready for static hosting.
