PCTN Fertilizer Shop

A premium, farmer-friendly multi-page agriculture business website built with Next.js, React, TypeScript, and Tailwind CSS.

Frontend · Next.js
Frontend Developer

About this Project

PCTN Fertilizer Shop is a multi-page agriculture business website built for a family-owned supply business in Cambodia, founded in 2023. The site presents products, services, gallery, and business information with a professional brand presence.

The experience is designed to be modern and easy to navigate for farmers, with a mobile-first responsive layout, reusable shadcn/ui components, and fast page transitions across six routes: Home, Products, About, Services, Gallery, and Contact.

Key Features

Multi-page layout tailored for an agriculture business
Mobile-first, responsive design
Reusable UI components built with shadcn/ui
Clean typography and clear visual hierarchy
Optimised performance and fast page transitions
Clear calls-to-action and contact paths

Key Achievements

1

Structured a six-page Next.js site with a consistent, reusable component system.

2

Built a mobile-first interface aimed at farmers, prioritising readability and clear contact paths.

3

Planned a roadmap toward a product catalog, online ordering, and an admin dashboard.
